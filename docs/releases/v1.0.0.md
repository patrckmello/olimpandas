# Olimpandas v1.0.0

Data: 26/11/2026

A v1.0.0 representa o fechamento da entrega acadêmica do Olimpandas e o primeiro vertical slice completo do projeto.

## Destaques

- Circuito Olímpico local 1v1 validado ponta a ponta.
- Quatro personagens jogáveis: Panda-gigante, Urso-polar, Grizzly e Urso-de-óculos.
- Quatro modalidades: 100m com barreiras, Salto a distância, Canoagem e Pescaria.
- Sorteio de modalidades, medalhas e vitória geral em melhor de 3.
- Seleção de personagens independente para P1 e P2.
- Pódio, revanche e troca de personagens.
- HUDs específicos das provas.
- Menu, pausa, opções de áudio, tela cheia, controles e créditos.
- Música e efeitos sonoros.
- Fluxo validado em playtest humano pelo time em 26/11/2026.

## Plataformas-alvo

- Windows x64
- Linux x64

Nomes recomendados para os pacotes da release:

- `Olimpandas-v1.0.0-Windows-x64.zip`
- `Olimpandas-v1.0.0-Linux-x64.zip`

## Como jogar

O fluxo é:

`MainMenu → CharacterSelect → CircuitDraw → modalidade → Podium → próxima modalidade`

O primeiro jogador a conquistar duas medalhas vence o Circuito Olímpico.

Consulte o [README](../../README.md) para controles e instruções completas de execução no Windows, Linux e Unity Editor.
